Duely

1v1 skill games, played for real stakes.

Duely is a head-to-head skill gaming platform. Pick a game, set a stake, and play a live 1v1 match against another person or against a bot. Matches are decided on skill — reaction, accuracy and speed — never on chance.

Games include Color Rush, Block Burst, Word VS, Car Dash, Tower, Coin Flip and Blackjack, each playable solo, against a bot, or ranked against another player.

Duely needs JavaScript to run. Please enable it, or open www.duely.us in a current browser.
