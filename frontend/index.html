Duely.

Live 1v1 matches, played for real stakes.

Duely is a head-to-head gaming platform. Pick a game, set a stake, and play a live 1v1 match against another player or against a bot. Most of the games are pure skill — reaction, accuracy and speed decide them.

Seven games: Block Burst, Rush Hour, Color Rush, Tower, Word VS, Coin Flip and Blackjack. Each can be played solo, against a bot, or ranked against another player.

Duely needs JavaScript to run. If this screen stays put, enable JavaScript or open www.duely.us in a current browser.
